# UnlockAllTools
Mod for unlocking all tools in Hollow Knight: Silksong

Unlock all tools and crests.

Does not unlock any skill.

You will have items that you are not supossed to have, for example a tool and its upgrade. Should not be a problem.

Just made this because a NPC that was supossed to give me a tool died, maybe this is your case.

Enjoy.


Installation:
- Install BepInEx
- Download the mod .zip and extract it into your game's root folder. Should look like <GameFolder>/BepInEx/plugins/UnlockAllTools/UnlockAllTools.dll

Usage:
- When the mod is already installed, open the game
- Two configuration files will be created in `<GameFolder>/BepInEx/config`: `UnlockTool.cfg` and `UnlockCrest.cfg`
- Each file show the name of all the tools or crests as `-Name`
- Now you have to change the first character of the tool or crest you want to unlock, e.g. `+Name`
- When you load a game, the tools and crests which you selected will be unlocked

*Ensure you remove/update the config files after unlocking anything, so you don't mess any other save by error
