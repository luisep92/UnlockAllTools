# UnlockAllTools
Mod for unlocking all tools in Hollow Knight: Silksong

Unlock all tools and crests.

Does not unlock any skill.

You will have items that you are not supossed to have, for example a tool and its upgrade. Should not be a problem.

Just made this because a NPC that was supossed to give me a tool died, maybe this is your case.

Be aware the mod executes everytime you fresh start the game. You can completely remove it after you unlock the tools so you don't break any other save.

Enjoy.


Installation:
- Install BepInEx
- Download the mod .zip and extract it into your game's root folder. Should look like <GameFolder>/BepInEx/plugins/UnlockAllTools/UnlockAllTools.dll
